# Нагрузочное тестирование

Нагрузочный генератор не включён в Compose и не запускается автоматически. Перед тестом поднимите demo и используйте отдельную машину с k6:

```bash
k6 run --vus 10 --duration 30s --env BASE_URL=http://localhost:8088 scripts/load-test.js
```

Сценарий должен использовать только тестового пользователя и read-only API. Не выполняйте нагрузочные тесты против production без согласованного лимита соединений PostgreSQL и окна обслуживания.
