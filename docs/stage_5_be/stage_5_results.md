Stage 5 — что сделано
CRM научилась принимать внешние данные и связывать их с конкретными партнёрскими программами.
Теперь путь данных выглядит так:
Файл / demo-сигнал
→ обработка и проверка
→ CRM-реестр сигналов
→ сопоставление с программой
→ метрики программы
→ интерфейс KAM / MANAGER / ADMIN
Что умеет система:
- Загружать предоставленные файлы:
  - каталог вендоров и продуктов;
  - B2C-пользователей;
  - B2C-заказы.
- Не переносить лишние персональные данные в рабочую CRM: паспорт, СНИЛС и другие поля не становятся данными карточки студента.
- Не считать строки payment JSON подтверждёнными оплатами или выручкой.
- Не угадывать вуз или программу по имени человека либо похожему названию курса.
- Оставлять неоднозначные записи в корректном статусе unmatched.
- Позволять ADMIN вручную связать курс и поток с ProgramInstance, после чего записи перепроцессируются.
- Обновлять метрики программы:
  - заявки;
  - студенты;
  - потоки;
  - записи B2C-заказов;
  - время последнего сигнала Website, LMS и B2C.
- Отличать данные заказчика (PROVIDED) от командных demo fixtures (DEMO/STUB).
- Не менять Health только из-за отсутствия B2C-заказов и не закрывать этапы workflow автоматически.
Как показать на демо
1. Запустить миграции и seed:
docker compose run --rm backend alembic upgrade head
docker compose run --rm backend python scripts/seed_demo_data.py
2. Войти как ADMIN и открыть:
Управление → Интеграции
3. Загрузить:
local_docs/file_examples/Вендоры.xlsx
local_docs/file_examples/Загрузка пользователей.xlsx
local_docs/file_examples/Данные оплат.json
4. В diagnostics показать два результата:
   - Инженер-тестировщик, поток 1 — сопоставится автоматически: mapping создаётся demo seed.
   - Остальные записи — unmatched: система не придумывает связь с вузом.
5. Выбрать любую unmatched B2C-запись, нажать «Сопоставить», выбрать организацию и ProgramInstance, затем «Сохранить и перепроцессить».
6. Показать, что запись стала mapped, а на странице программы в блоке «Интеграционные B2C-метрики» увеличился счётчик B2C-заказов.
7. Отдельно запустить Website или LMS TEAM DEMO fixture и показать метку DEMO/STUB; загруженные файлы имеют метку PROVIDED.
8. Войти как KAM или MANAGER:
   - интеграционная диагностика и загрузка недоступны;
   - KAM видит метрики только своих программ;
   - raw B2C payload не показывается пользователям этих ролей.
