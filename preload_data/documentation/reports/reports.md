# Отчёты

скр 13
Раздел «Отчёты» предназначен для просмотра, фильтрации и выгрузки данных по программам и по работе команды. Набор доступных отчётов и данных зависит от роли пользователя.

## Доступ по ролям

KAM — видит отчёт только по программам, за которые он отвечает.
Руководитель — видит все типы отчётов, но данные ограничены его командой KAM и программами, закреплёнными за сотрудниками этой команды.
Администратор — видит все типы отчётов и данные по всем доступным организациям, программам и сотрудникам.

## Типы отчётов

скр. 14
Переключатель типа отчёта — позволяет выбрать, какой отчёт отображать: по программам, рейтингу образовательных программ или менеджерам.

### тип отчёта: Программы

скр 15.
Отчёт с подробной информацией по программам и их текущему состоянию. Позволяет посмотреть основные показатели программ, организаций, ИТ-продуктов и связанных с ними взаимодействий.
скр. 16
В таблице можно вывести следующие данные:

- Организация;
- Направление;
- ИТ-продукт;
- Ответственный;
- Этап;
- Статус;
- Health;
- Плейбук;
- Номер лицензии;
- Заявки;
- Студенты;
- Потоки.

### тип отчёта: Рейтинг образовательных программ

Доступен Руководителю и Администратору.
скр. 17
Отчёт для сравнения образовательных программ по результатам их использования и внедрения.
Отчёт позволяет сравнить образовательные программы по их востребованности, степени внедрения в организациях и другим показателям.
Для каждой образовательной программы отображаются:

- Программа — название образовательной программы;
- ИТ-продукт — связанный с программой продукт;
- Вузы — количество организаций, в которых представлена программа;
- В эксплуатации — сколько внедрений уже запущено относительно общего количества;
- Доля внедрения — процент организаций, в которых программа уже введена в эксплуатацию;
- Заявки — количество заявок на обучение;
- Студенты — количество обучающихся;
- Потоки — количество учебных потоков;
- Индекс востребованности — сводный показатель востребованности образовательной программы.
  Отчёт помогает посмотреть на программу с двух сторон: насколько она востребована и насколько широко фактически внедрена.

#### Детализация программы в разделе Рейтинг образовательных программ

скр. 18.
При наведении на информационный значок в строке программы открывается всплывающее окно с подробной информацией по выбранной образовательной программе.
Основная таблица показывает общий результат образовательной программы (агрегированные показатели), а всплывающее окно позволяет увидеть, из каких конкретных взаимодействий с вузами этот результат складывается.

### тип отчёта: Менеджеры

скр. 19
Отчёт по работе KAM. Доступен Руководителю и Администратору.
Позволяет посмотреть показатели каждого менеджера и подробнее оценить состояние закреплённого за ним портфеля программ.

#### Детализация показателей KAM в разделе Менеджеры

скр. 20.
При наведении на информационный значок в строке менеджера открывается всплывающее окно с подробной информацией по показателям выбранного сотрудника.
Основная таблица показывает общий результат работы менеджера (агрегированные показатели), а всплывающее окно позволяет увидеть работу менеджера с конкретной программой и вузом.

## Функционал

#### Фильтры

Для каждого типа отчёта используется свой набор фильтров. Они позволяют сузить данные перед формированием отчёта и оставить только нужную выборку.

скр. 21

- Программы — фильтрация по периоду, организации, направлению, ИТ-продукту, ответственному, плейбуку, этапу, Health и статусу.

скр. 22

- Рейтинг образовательных программ — фильтрация по периоду, организации, программе, ИТ-продукту и ответственному.

скр. 23

- Менеджеры — переключение между всей командой и отдельными KAM для просмотра показателей конкретного сотрудника.

скр. 24
После выбора параметров необходимо нажать «Сформировать отчёт» — выбранные фильтры применяются к данным отчёта.
скр 25
Кнопка «Сбросить» очищает фильтры только в текущем типе отчёта и возвращает их к исходному состоянию.

При переключении между типами отчётов выбранные значения сохраняются, поэтому пользователь может перейти в другой отчёт и затем вернуться обратно, не настраивая фильтры заново.
скр 26
Кнопка «Сбросить все фильтры» очищает выбранные параметры сразу для всех типов отчётов.
Состояние фильтров также сохраняется в URL страницы. Это позволяет:

- не потерять выбранные параметры после обновления страницы;
- использовать кнопки браузера «Назад» и «Вперёд» без потери состояния;
- скопировать ссылку на уже настроенный отчёт и открыть его с теми же фильтрами;
- передать другому пользователю ссылку на конкретную выборку данных.

#### Настройка колонок отчёта

скр. 27
Кнопка «Колонки» позволяет настроить состав таблицы и оставить только те данные, которые нужны пользователю. Состав таблицы обновляется после нажатия на кнопку «Применить»

#### Выгрузка отчёта

скр. 28 ПРИЛОЖИТЬ СВОЙ СКРИН ГДЕ ЕСТЬ JSON
Кнопка «Скачать» позволяет выгрузить сформированный отчёт в удобном формате. Доступны варианты:

- Excel (.xlsx);
- Excel (.xls);
- PDF (.pdf);
- JSON (.json).
