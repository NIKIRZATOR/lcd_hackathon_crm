# Главная страница

## Главная страница KAM

скрин 1.
Главная страница KAM — операционный рабочий стол для ежедневной работы с программами.
Страница собирает в одном месте:

- ключевые показатели по портфелю KAM;
- задачи, которые требуют действий сегодня;
- программы, требующие внимания;
- ближайшее учебное окно;
- новые сигналы из внешних источников — сайта и LMS.

### Сводные показатели

В верхней части страницы отображаются основные показатели текущего портфеля:
скрин 2.

- **Активных программ** — количество программ, находящихся в активной работе;
- **Задач на сегодня** — количество актуальных Next Best Action;
- **Требуют внимания** — количество программ, для которых обнаружены риски или отклонения;
- **До начала учебного семестра / учебного окна** — информация о ближайшем контрольном периоде.

### Очередь действий

Блок **«Очередь действий»** содержит сформированные системой задачи по программам KAM.
скрин 3.
Каждая задача относится к конкретной программе и содержит:

- уровень приоритета;
- вуз и образовательную программу;
- рекомендуемое следующее действие;
- срок выполнения;
- признак просрочки;
- кнопку перехода в карточку программы.

Задачи визуально разделяются по уровню критичности:

- **Критический**;
- **Высокий**;
- **Средний**;
- **Низкий**.

Очередь позволяет KAM начинать работу с наиболее важных и срочных действий.
Задачи можно фильтровать / сортировать по приоритету.

### Next Best Action

**Next Best Action (NBA)** — рекомендуемое системой следующее действие по конкретной программе.

скрин 3_1
Рекомендация формируется на основании текущего состояния программы, этапа workflow, сроков, данных взаимодействия и поступивших сигналов. После выполнения действия соответствующий пункт закрывается в карточке программы, и система может сформировать следующий Next Best Action.

### Здоровье портфеля

скрин 4.
Сводка состояния активных программ KAM по Health Score каждой программы.

Health Score — это динамический показатель состояния конкретной программы в диапазоне от 0 до 100, который показывает, насколько стабильно сейчас идёт взаимодействие с учебным заведением и есть ли факторы, угрожающие внедрению или обучению (просроченные этапы, проблемы с лицензией или преподавателем, отсутствие активности в LMS, риск не попасть в учебное окно).

Программы распределяются по уровням:

- зелёные — работают в штатном режиме;
- жёлтые — требуют внимания;
- красные — находятся в критическом состоянии.
  Из блока «Здоровье портфеля» можно перейти в раздел отчётов и посмотреть подробную информацию по программам.

### Учебное окно

скрин 5.
Показывает ближайшую контрольную дату учебного периода и количество программ, по которым необходимо выполнить действия до наступления этой даты.

### Сигналы сайта и LMS

скрин 6.
Блок с дополнительными сигналами из внешних источников, например:

- изменения активности студентов в LMS;
- новые заявки с сайта;
- длительное отсутствие активности.
  Сигналы позволяют быстро перейти к соответствующей программе и разобраться в ситуации.

## Главная страница Руководителя

скрин 7.

Главная страница Руководителя — это рабочий дашборд для контроля команды KAM и общего состояния портфеля программ. Страница помогает оценить нагрузку сотрудников, увидеть проблемные организации и программы, а также понять, на каких этапах сейчас возникли задержки.

### Сводные показатели

скрин 8.
KAM в команде — количество сотрудников в команде.
Организации — количество организаций в портфеле.
Активные программы — общее количество программ в работе.
Красные программы — количество программ в критическом состоянии по Health Score.

### Нагрузка KAM

скр 9
Таблица с текущей нагрузкой сотрудников команды.
Для каждого KAM отображаются:

- количество программ;
- количество красных программ;
- просроченные задачи;
- количество программ, требующих внимания.
  Из блока «Нагрузка KAM» можно выполнить переназначение программ между сотрудниками. Также из таблицы можно перейти в отчёт по менеджерам KAM, где доступна более подробная информация по работе каждого сотрудника.

### Состояние организаций

скр 10
Показывает состояние организаций по самому низкому Health Score среди их активных программ.
Для каждой организации отображаются:

- название организации;
- ответственный KAM;
- минимальный Health Score среди активных программ;
- количество активных программ.
  Такой подход позволяет быстро увидеть организации, в которых есть хотя бы одна программа с низким показателем Health.

### Где застряли программы

скр 11
Показывает, сколько программ сейчас находится на каждом этапе рабочего процесса.
Этапы отсортированы по количеству программ: чем больше программ находится на этапе, тем выше он отображается в списке. Это помогает быстро увидеть, где скопилось больше всего программ и какие этапы требуют внимания.

### Рейтинг программ

скр 12
Показывает топ-3 образовательных программы с наиболее высокими показателями востребованности.
В рейтинге отображаются:

- позиция программы;
- название;
- индекс востребованности;
- дополнительные показатели, например количество заявок, студентов и потоков.
  Из блока можно перейти в отчёт по рейтингу образовательных программ, где дополнительно отображается доля внедрения и более подробные показатели по каждой образовательной программе.
